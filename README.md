# CrewAI Project

(i) Designed an end-to-end blog automation framework using CrewAI, enabling automatic blog generation from YouTube video content.

(ii) Created two AI agents — a Researcher to fetch and analyze YouTube video transcripts, and a Content Writer to generate blog pages from extracted content.

(iii) Implemented the three key components — Agents, Tasks, Tools — and integrated them in crew.py to build a sequential workflow connecting researcher output to content writing.

(iv) Developed and integrated custom tools (YT transcription tool) to support agents in extracting and processing video content.
